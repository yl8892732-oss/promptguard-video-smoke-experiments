# PromptGuard Smoke Experiment Report

## Scope

This report covers the first real CogVideoX-2B smoke test using PromptGuard. It is a **small-sample
inference smoke test**, not a complete benchmark, a full evaluation, or a paper-level experiment.
It contains two control runs and six benchmark prompts (three from T2V-CompBench V1 and three from
VBench).

## Frozen generation settings

- mode: `promptguard` for benchmark records; controls run `dense` then `promptguard`
- seed: `42` for every record
- steps: `8`; frames: `9`; resolution: `720x480`
- guidance: `6.0`
- density: `0.4`; alpha: `0.2`; delta: `0.05`
- block size: `256`; warmup: `1`
- offload: `model`; VRAM cap: `23 GiB`

Each record was generated by a separate `generate.py` process so PromptGuard controller/router state
could not carry over between prompts.

## Validation performed

1. Re-read every generated JSON and checked `finite`, video shape, seed, settings, and routing.
2. Compared each JSON's `benchmark`, `group`, and `prompt_id` against the selected manifest record.
3. Decoded every MP4 with the installed imageio-ffmpeg and checked dimensions, frame count, and
   non-constant pixel statistics.
4. Verified paired MP4/JSON existence and file sizes.

The delivery copy of each JSON has its `model_path` normalized to the project-relative `model`;
prompt text, IDs, measurements, routing data, and generation settings are unchanged. Local
executable paths in the small `artifacts/dry_runs` test fixtures were also normalized.

## Limitations

- Only six benchmark prompts and two controls were run; this does not cover the full T2V-CompBench
  or VBench suites.
- No official evaluator or metric computation was run.
- No training, fine-tuning, or ablation study was performed.
- Generation is stochastic; a reproduction on a different GPU/driver may produce different pixels,
  file sizes, and timing.
- The A40 run (96 passed) and the local Windows delivery-copy test (94 passed, 2 skipped due to
  `sm_120`) are separate results; the local skips are not failures.
